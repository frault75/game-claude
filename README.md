# Trait

An open-world action RPG painted in ink wash, for desktop and mobile browsers: explore, cleanse camps, level up, find the master's coloured inks (each one a different weapon) and defeat the guardians. Everything — art, music, sound — is generated by code at runtime.

**Play:** https://frault75.github.io/game-claude/

See [DESIGN.md](DESIGN.md) for the full design.

## Develop

```sh
npm install
npm run dev      # local server
npm run build    # typecheck + static build in dist/
```

Pushing to `main` builds and deploys to GitHub Pages (Settings → Pages → Source: GitHub Actions).

## Controls

| Action | Desktop | Mobile |
|---|---|---|
| Walk | Left click (hold to follow the cursor), or WASD / ZQSD | Tap (hold to follow your finger) |
| Attack a foe | Left click on it | Tap on it |
| **Draw with ink** | Right-button drag (right click = straight stroke), or Space | Quick swipe |
| Change ink | Keys 1-4, mouse wheel | Ink pots (bottom right) |

Inks: vermilion (run along the stroke and cut; loops burst), indigo (freezes; loops hold everything still), gold (lightning along the stroke; loops become a storm).

## Debug

- `F3` or `` ` `` toggles the debug overlay (FPS, area, boss state, thread state).
- Add `?debug` to the URL for test keys: `H` invulnerable, `T` teleport between shrines and the stone circle, `L` +200 XP, `U` unlock inks, `K` sets enemies to 1 HP, `B` line boil.
- Add `?reset` to start a new save.
