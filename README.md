# Trait

A fast ink-wash action game for the desktop browser: every dodge is a brushstroke, every closed loop a burst of ink. Everything — art, music, sound — is generated by code at runtime.

**Play:** https://frault75.github.io/game-claude/

See [DESIGN.md](DESIGN.md) for the full design.

## Develop

```sh
npm install
npm run dev      # local server
npm run build    # typecheck + static build in dist/
```

Pushing to `main` builds and deploys to GitHub Pages (Settings → Pages → Source: GitHub Actions).

## Controls

| Action | Keyboard + mouse | Gamepad |
|---|---|---|
| Move | WASD / ZQSD / arrows | Left stick |
| **Trait** (dash towards the cursor, leaves a stroke) | Right click or Space | A (stick direction) |
| Brush strike | Left click | X |

Cross your own fresh stroke to close a loop: everything inside bursts (ensō).

## Debug

- `F3` or `` ` `` toggles the debug overlay (FPS, area, boss state, thread state).
- Add `?debug` to the URL for test keys: `H` invulnerable, `B` line boil on/off, `K` sets enemies to 1 HP.
